# 🎮 Liar Bar

Unity로 개발한 **심리 추리 카드 게임** 입니다.  
제한된 카드와 시간을 활용해 **진실과 거짓말을 추리**하며 상대를 탈락시키고 마지막 생존자가 되는 것이 목표입니다.

- **플랫폼** : PC (Windows)
- **Unity 버전** : 6000.0.50f1
- **📄 기술문서 링크** : [기술문서 링크](https://drive.google.com/drive/folders/1gcQ5xP3MlVEgDHBIyB4wQR_PSS4JhcN1?hl=ko)
- **📒 개발 일지** : [개발 일지 노션 링크](https://mincheolstudy.notion.site/LiarBar-2a9d4b6c965c80c9b070fc6b0210bd76)
---

## 🎯 기술 목표

이 프로젝트는 다음과 같은 기술적 목표 및 학습을 중심으로 개발되었습니다:

- **Photon Voice 2** 기반 실시간 음성 채팅 구현
- **서버 권한 구조** 기반 게임 로직 동기화 구현
- Firebase를 활용한 **플레이어 데이터 저장**
- 팀원과의 커뮤니케이션 협업
